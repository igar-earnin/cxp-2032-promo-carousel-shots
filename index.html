How the carousel works

One PromotionCarouselCardProvider and one PromotionCarouselCardModel. LevelUpCardFactory picks the ViewHolder from cxp-home-tiles-restyle → promo_enabled. This PR only changes the DSV2 tile background.

Android has no NativePromoCard path

Unlike iOS, Android never hardcodes green for badge or strikethrough. Every loaded home-card promotion goes through DS.PromoCard (legacy) or TileContainer (DSV2). DSV2 also drops the optional product label and uses attributes.content as the title.

Layout states

Shared model: Hidden / Empty / Loading / Content. Empty renders nothing. Loading stays on elevated / white and is unchanged. Legacy loading is a single skeleton; DSV2 loading is two peeking skeletons.

Before / after — every content state × color

Legacy before and after are identical (mapper extract only). DSV2 before is always bg.elevated (#FFFFFF light / #000 dark). DSV2 after uses the mapped tint. Filter hides rows only — the table stays open.

Dark appearance — DSV2 only

Legacy DS.Theme { } is light-locked. DSV2 ViewHolder uses DSV2.Theme(enableDarkMode = true), so title / CTA stay theme-aware. After this PR a pale yellow tile can sit under white dark-mode title text. Loading still uses elevated (black in dark).
